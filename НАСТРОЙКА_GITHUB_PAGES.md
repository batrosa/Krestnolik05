## 📋 Простая инструкция (2 минуты):

### Шаг 1: Откройте настройки репозитория

1. Перейдите на https://github.com/batrosa/Krestnolik05
2. Нажмите на вкладку **"Settings"** (Настройки) в верхнем меню

   ```
   Code  Issues  Pull requests  Actions  Projects  Settings  ← Нажмите сюда
   ```

---

### Шаг 2: Найдите раздел Pages

1. В левом боковом меню прокрутите вниз
2. Найдите и нажмите на **"Pages"** (в разделе "Code and automation")

   ```
   Code and automation
   ├─ Branches
   ├─ Tags
   ├─ Actions
   └─ Pages  ← Нажмите сюда
   ```

---

### Шаг 3: Включите GitHub Pages

В разделе **"Build and deployment"** (Сборка и развертывание):

1. **Source** (Источник): Выберите **"GitHub Actions"**

   ⚠️ ВАЖНО: Не выбирайте "Deploy from a branch"!
   Выберите именно **"GitHub Actions"**

2. Нажмите **"Save"** (если кнопка появится)

---

### Шаг 4: Запустите деплой

После сохранения:

1. Перейдите на вкладку **"Actions"** вверху страницы
2. Вы увидите workflow **"Deploy to GitHub Pages"**
3. Если он не запустился автоматически:
   - Нажмите на workflow
   - Нажмите кнопку **"Run workflow"** (справа)
   - Нажмите зеленую кнопку **"Run workflow"** в выпадающем меню

---

### Шаг 5: Дождитесь завершения деплоя

1. Workflow запустится (появится желтый кружок 🟡)
2. Подождите 30-60 секунд
3. Когда появится зеленая галочка ✅ - готово!

---

### Шаг 6: Получите ссылку на приложение! 🎉

Ваше приложение будет доступно по адресу:

```
https://batrosa.github.io/Krestnolik05/
```

**Откройте эту ссылку на iPhone и наслаждайтесь!** 📱

## ❓ Часто задаваемые вопросы

### Q: Где найти ссылку на сайт после настройки?
**A:** Вернитесь в Settings → Pages, и вверху будет зеленая плашка с ссылкой на ваш сайт.

### Q: Сколько времени занимает деплой?
**A:** Обычно 30-60 секунд. Первый раз может занять до 2 минут.

### Q: Нужно ли делать это каждый раз?
**A:** Нет! Настройка делается один раз. После этого сайт будет обновляться автоматически при каждом push.

### Q: Сайт не открывается
**A:** Подождите 2-3 минуты после первого деплоя. GitHub Pages нужно время для активации.

### Q: Можно ли изменить ссылку?
**A:** Базовая часть (batrosa.github.io/Krestnolik05/) фиксирована. Но вы можете настроить свой домен в настройках Pages.

### Q: Приложение обновилось в коде, но не на сайте
**A:**
1. Убедитесь, что изменения закоммичены и запушены
2. Подождите 1-2 минуты
3. Обновите страницу с очисткой кэша (Ctrl+Shift+R)
