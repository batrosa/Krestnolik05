# ARC Raiders - База предметов

Минималистичное веб-приложение для просмотра всех предметов из игры ARC Raiders с функцией поиска и фильтрации.

## 🎯 Возможности

- **🔍 Поиск** - поиск по названию и описанию предметов на русском и английском языках
- **♻️ Фильтр "Только для переработки"** - показывает предметы, которые не используются в крафте или квестах
- **🔧 Фильтр "Крафтимые"** - показывает только предметы, которые можно создать
- **📊 Фильтр по редкости** - Common, Uncommon, Rare, Epic, Legendary
- **📦 Фильтр по типу** - материалы, оружие, расходники и т.д.
- **📱 Адаптивный дизайн** - отлично работает на мобильных устройствах
- **🌍 Русский язык** - весь интерфейс и данные на русском

## 🚀 Как использовать

### Вариант 1: Открыть локально

1. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge)
2. Приложение автоматически загрузит актуальные данные из GitHub
3. Подождите несколько секунд пока загрузятся все предметы

### Вариант 2: Через веб-сервер

```bash
# Если у вас установлен Python 3
cd ardb-items-app
python3 -m http.server 8000

# Или с Node.js
npx http-server -p 8000

# Затем откройте в браузере
# http://localhost:8000
```

## 📋 Информация о предметах

Для каждого предмета отображается:

- **Название** (на русском)
- **Тип** предмета
- **Редкость** (с цветовой маркировкой)
- **Описание**
- **Стоимость** 💰
- **Вес** ⚖️
- **Размер стека** 📦
- **Статус крафта**:
  - 🔧 Крафтим - предмет можно создать
  - 🔨 Используется в крафте - предмет нужен для создания других предметов
  - ♻️ Только переработка - предмет можно только переработать (не используется в крафте или квестах)
  - ♻️ Перерабатывается - предмет можно переработать

## 🎨 Особенности дизайна

- **Минимализм** - темная тема, чистый интерфейс без лишних элементов
- **Цветовая кодировка редкости**:
  - Серый - Обычный
  - Зеленый - Необычный
  - Синий - Редкий
  - Фиолетовый - Эпический
  - Оранжевый - Легендарный
- **Адаптивная сетка** - автоматически подстраивается под размер экрана
- **Плавные анимации** - при наведении на карточки предметов

## 🔧 Технические детали

- **Один файл** - всё приложение в одном HTML файле
- **Без зависимостей** - не требует установки библиотек
- **Загрузка данных** - автоматическая загрузка из GitHub API
- **Кеширование** - данные загружаются один раз при открытии
- **Производительность** - оптимизированная загрузка батчами по 10 файлов
