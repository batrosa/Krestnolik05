# 🎮 ARC Raiders - База предметов

Минималистичное веб-приложение для просмотра всех предметов из игры ARC Raiders с поиском и фильтрацией.

## 🚀 Быстрый старт на iPhone

**Откройте в Safari:**

```

**После настройки GitHub Pages:**
```

## ✨ Возможности приложения

- 🔍 **Поиск** по названию и описанию (русский/английский)
- ♻️ **Фильтр "Только для переработки"** - предметы без использования в крафте
- 🔧 **Фильтр "Крафтимые"** - предметы, которые можно создать
- 📊 **Фильтры** по редкости и типу
- 📱 **Адаптивный дизайн** для мобильных устройств
- 🌍 **Полностью на русском языке**
- ⚡ **Автоматическая загрузка** данных из GitHub (399 предметов)

## 📊 Данные

- 399 предметов
- Полная информация о крафте, переработке, характеристиках
- Автоматическое обновление при релизе новых данных
