# 📱 Как запустить приложение на iPhone

## Способ 1: Через GitHub Pages (Рекомендуется) ⭐

Это самый удобный способ - приложение будет доступно как обычный сайт.

### Шаги для владельца репозитория:

1. **Откройте настройки репозитория**
   - Перейдите на https://github.com/batrosa/Krestnolik05
   - Нажмите на вкладку **Settings** (Настройки)

2. **Включите GitHub Pages**
   - В левом меню найдите раздел **Pages**
   - В разделе **Source** (Источник) выберите:
     - Branch: `claude/ardb-items-app-ru-01XtnykyxhvfbQe1pyFFpQDu`
     - Folder: `/docs`
   - Нажмите **Save**

3. **Получите ссылку**
   - Через несколько секунд появится ссылка вида:
   - `https://batrosa.github.io/Krestnolik05/`

4. **Откройте на iPhone**
   - Откройте эту ссылку в Safari на iPhone
   - Готово! Приложение работает как полноценный сайт

### 📌 Добавить на главный экран iPhone:

1. Откройте сайт в Safari
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Выберите **"На экран "Домой"**
4. Приложение появится как иконка на главном экране!

## Способ 2: Через raw.githack.com (Быстрый запуск) 🚀

Если не хотите настраивать GitHub Pages, используйте этот способ:

### На iPhone:

1. Откройте Safari
2. Перейдите по ссылке:
```
https://raw.githack.com/batrosa/Krestnolik05/claude/ardb-items-app-ru-01XtnykyxhvfbQe1pyFFpQDu/ardb-items-app/index.html
```

3. Приложение сразу загрузится и заработает!

**Примечание**: Этот способ работает сразу, но для постоянного использования лучше настроить GitHub Pages.

## Способ 3: Через htmlpreview.github.io ⚡

Ещё один быстрый способ:

1. Откройте Safari на iPhone
2. Перейдите по ссылке:
```
https://htmlpreview.github.io/?https://github.com/batrosa/Krestnolik05/blob/claude/ardb-items-app-ru-01XtnykyxhvfbQe1pyFFpQDu/ardb-items-app/index.html
```

## Способ 4: Скачать и открыть локально 📥

1. Откройте https://github.com/batrosa/Krestnolik05
2. Перейдите в папку `ardb-items-app`
3. Откройте файл `index.html`
4. Нажмите **Raw** (справа вверху)
5. Нажмите на три точки в Safari → **Загрузить связанный файл**
6. Откройте загруженный файл в приложении **Файлы**
7. Нажмите на файл - он откроется в Safari

## ❓ Возможные проблемы

### Приложение не загружается
- Проверьте подключение к интернету
- Попробуйте обновить страницу
- Очистите кэш Safari: Настройки → Safari → Очистить историю и данные

### Данные не загружаются
- Приложению нужен интернет для загрузки данных из GitHub
- Подождите несколько секунд - загружается 399 предметов
- Проверьте, что Safari может обращаться к GitHub

### Не работает на старом iPhone
- Приложение требует современный браузер
- Попробуйте обновить iOS до последней версии
- Минимум: iOS 12+, Safari 12+

## 💡 Полезные советы для iPhone

1. **Полноэкранный режим**: Прокрутите страницу вниз, чтобы скрыть адресную строку Safari

2. **Быстрый поиск**: Используйте панель поиска в верхней части приложения

3. **Сохранение**: Добавьте сайт на главный экран для быстрого доступа

4. **Офлайн**: После первой загрузки, данные кешируются браузером, но для обновления нужен интернет

5. **Поделиться**: Используйте кнопку "Поделиться" в Safari, чтобы отправить ссылку друзьям
