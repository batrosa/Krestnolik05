# ARC Raiders - База предметов

## 📱 Как использовать на iPhone

Это приложение оптимизировано для мобильных устройств, включая iPhone!

### ⚙️ Настройка GitHub Pages:

**👉 [ИНСТРУКЦИЯ ПО НАСТРОЙКЕ](../НАСТРОЙКА_GITHUB_PAGES.md)** (2 минуты)

### Быстрый доступ:

После включения GitHub Pages, приложение будет доступно по адресу:
```
https://batrosa.github.io/Krestnolik05/
```

### Добавить на главный экран:

1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Выберите "На экран Домой"
4. Приложение появится как иконка!

---

## 🎯 О приложении

Минималистичное веб-приложение для просмотра всех предметов из игры ARC Raiders.

### Возможности:
- 🔍 Поиск по названию и описанию
- ♻️ Фильтр "Только для переработки"
- 🔧 Фильтр по крафтимым предметам
- 📊 Фильтры по редкости и типу
- 📱 Адаптивный дизайн для мобильных
- 🌍 Полностью на русском языке

### Данные:
- Загружается автоматически из GitHub
- Всего 399 предметов
- Актуальная информация из игры
