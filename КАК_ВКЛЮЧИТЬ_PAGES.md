# ⚡ Быстрая инструкция: Включение GitHub Pages

## ❗ Ошибка которую вы видите:

```
Error: Get Pages site failed. Please verify that the repository has Pages enabled
```

Это значит, что **GitHub Pages просто не включен** в настройках репозитория. Давайте это исправим!

---

## 🎯 Решение (3 простых шага):

### Шаг 1: Откройте настройки Pages

Нажмите на эту ссылку (откроется прямо на нужной странице):

```
https://github.com/batrosa/Krestnolik05/settings/pages
```

**ИЛИ** сделайте вручную:
1. Откройте https://github.com/batrosa/Krestnolik05
2. Нажмите **Settings** (вверху справа)
3. В левом меню найдите **Pages** (в разделе "Code and automation")

---

### Шаг 2: Выберите источник

На странице Pages найдите раздел **"Build and deployment"**

Вы увидите выпадающий список **"Source"**:

**ВАЖНО! Выберите именно:**
```
☑️ GitHub Actions
```

**НЕ ВЫБИРАЙТЕ:**
```
❌ Deploy from a branch
```

---

### Шаг 3: Готово! Теперь запустите деплой

После выбора "GitHub Actions":

1. Перейдите на вкладку **Actions**: https://github.com/batrosa/Krestnolik05/actions
2. Нажмите на workflow **"Deploy to GitHub Pages"** (слева в списке)
3. Нажмите кнопку **"Run workflow"** (справа, синяя кнопка)
4. Выберите ветку `claude/ardb-items-app-ru-01XtnykyxhvfbQe1pyFFpQDu`
5. Нажмите **"Run workflow"** ещё раз (подтверждение)

---

## ⏱️ Сколько ждать?

- GitHub запустит деплой (появится желтый кружок 🟡)
- Подождите 30-60 секунд
- Когда появится зеленая галочка ✅ - готово!

---

## 🎉 Проверка

После успешного деплоя, ваше приложение будет доступно по адресу:

```
https://batrosa.github.io/Krestnolik05/
```

Откройте эту ссылку в Safari на iPhone и добавьте на главный экран! 📱

## ❓ Что делать если не получается?

### Вариант A: Альтернативный метод (без GitHub Actions)

Если GitHub Actions не работает, используйте старый способ:

1. На странице Settings → Pages
2. **Source**: выберите **"Deploy from a branch"**
3. **Branch**: выберите `claude/ardb-items-app-ru-01XtnykyxhvfbQe1pyFFpQDu`
4. **Folder**: выберите `/docs`
5. Нажмите **Save**

Подождите 2 минуты, и сайт заработает!

---

### Вариант B: Используйте прямую ссылку (работает уже сейчас!)
